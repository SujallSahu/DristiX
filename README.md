# DristiX — An Accessible Web Examination Platform 

**DristiX** is an accessibility-first online examination and practice platform designed to help visually impaired and print-disabled candidates prepare for and participate in competitive examinations with greater independence.

The platform brings accessible exam delivery, assistive interaction, practice resources, and performance tracking together in one place.

**Live Platform:** https://dristix.vercel.app/  

## Why DristiX?

Traditional online examination systems can create barriers for candidates who rely on screen readers, keyboard navigation, magnification, or other assistive technologies. DristiX aims to make the examination experience more inclusive—from navigating the platform and understanding questions to completing tests and reviewing performance.

## Key Features

- **Keyboard-first navigation** across important platform workflows.
- **Screen-reader-friendly interactions** with accessible labels, focus handling, and live announcements.
- **Voice assistance and audio feedback** to support independent navigation and interaction.
- **Personalized accessibility settings**, including themes and adjustable text magnification.
- **Accessible exam experience** with question navigation, question palette, timer announcements, and submission confirmation.
- **Practice and mock examinations** to support preparation for competitive exams.
- **Performance insights** to help candidates review attempts and monitor progress.
- **Accessible learning content**, including support for mathematical expressions and document-based materials.
- **Student and administrator experiences** for examination participation and platform management.

## Technology

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB with Mongoose
- **Accessibility and content:** ARIA-oriented components, KaTeX, PDF.js, Web Audio API
- **Security and validation:** Helmet, CORS, Express rate limiting, Zod
- **AI integrations:** Google Gemini API (Multimodal Vision) & Groq (Whisper Audio Transcription & LLaMA) via secure backend proxy
